# Small Data, Big Questions

A self-contained educational website about computing ethics and children's online privacy. Open `index.html` directly in a browser; no build step or dependencies are required.

The interactive design review focuses on a fictional learning app, privacy-by-design questions, the U.S. Children's Online Privacy Protection Act (COPPA) and FTC Rule, and the ACM Code of Ethics. It is a focused introduction to parts of Performance Standard 5.3, not legal advice or a complete lesson on the standard.

## Student submission

Complete the scenario, then use the reflection form to explain the ethical issue and how it differs from the law, describe one decision and its feedback, and propose a revision. Ask a peer to test the site, record their feedback and one improvement, then download the reflection and test log as a text file. The draft stays in the current browser; it is not sent to a server.

For GitHub Pages, configure the repository to publish from `main` and `/(root)`. Once enabled, the public URL is <https://0bsinet.github.io/CS/>. Share that URL with a peer and include it with the downloaded reflection when submitting.
